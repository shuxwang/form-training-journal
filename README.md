# 塑形日志

适合手机的静态训练打卡网站，支持主屏幕安装与首次联网后的离线使用。

训练和身体记录保存在当前浏览器，不会上传到 GitHub；没有账号云同步。请定期导出 JSON 备份。

## 发布

将本目录文件放到 GitHub 仓库根目录，Settings → Pages → Deploy from a branch → main / (root) → Save。

发布地址一般为 `https://你的用户名.github.io/仓库名/`，以 Pages 页面给出的链接为准。

## 手机使用

Safari 或 Chrome 打开发布地址，添加到主屏幕。旧记录先从电脑导出，再在手机的“成长记录”导入。

公开仓库中的网页包含预设训练资料（年龄、身高、基准体重）；每日打卡和实际身体记录仅存在设备中。
